## What the spike does

1. Load mesh+diffuse package (`v02_texture_spike.package`)  
2. Remint **all 25 unique instances** to IDs not present in the donor (S4S-grade coexistence)  
3. Rewrite every embedded `u64` instance reference inside payloads (MLOD material TGIs, COBJ block, …)  
4. Rewrite all STBL locales: name=`CCStudio Test Mug`, desc=`Generated by CC Studio` (new FNV32 keys)  
5. Patch OBJD u32@8/@12 to those keys; write price `10` (f32@90 + u32 mirrors)  
6. Rename COBJ internal name to `CCStudio_TestMug_<stamp>_set1`  
7. **Keep tuning string** `object_light_table` (inherited)  
8. Preserve DST **content** hashes; MLOD hash changes only due to remapped embedded TGIs  

Does **not** retarget tuning to `prototype_RetailCompatible` (S4S does that for clean vase clones — documented debt).
